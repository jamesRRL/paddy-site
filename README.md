# paddy-site

Public pages for the **Paddy** iPhone app, served by GitHub Pages. No app code lives here.

| Page | URL | Used as |
|---|---|---|
| `privacy.md` | https://jamesrrl.github.io/paddy-site/privacy/ | App Store Privacy Policy URL, and the in-app link |
| `support.md` | https://jamesrrl.github.io/paddy-site/support/ | App Store Support URL |
| `index.md` | https://jamesrrl.github.io/paddy-site/ | landing page |

`privacy.md` is generated from `PRIVACY.md` in the private app repo, which is the single source of
truth — change the policy there first, then republish this file.
